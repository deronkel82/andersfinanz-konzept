# Anders Finanz – kompakter Website-Entwurf

Ein klickbarer Designentwurf auf Basis der Inhalte von [andersfinanz.de](https://andersfinanz.de/).

**Live-Demo:** [deronkel82.github.io/andersfinanz-konzept](https://deronkel82.github.io/andersfinanz-konzept/)

## Starten

- Unter Windows: `start-demo.bat` doppelklicken.
- Alternativ `index.html` direkt im Browser öffnen.
- Zum Beenden des lokalen Servers: `stop-demo.bat` doppelklicken.

Der Entwurf verändert die bestehende Website nicht. Termin-Buttons führen weiterhin zum vorhandenen Calendly-Link. Impressum und Datenschutz sind im Konzept Platzhalter, weil die bestehende Seite dafür ebenfalls keine echten Zielseiten verlinkt.

## Designgedanke

- deutlich kürzere Entscheidungsstrecke statt vieler ähnlicher Textblöcke
- zwei klare Zielgruppen direkt nebeneinander
- Leistungen kompakt als aufklappbare Liste
- fünf Prozessschritte auf drei verständliche Phasen verdichtet
- menschliches Editorial-Bild statt klassischer Finanz-Stockmotive
- bestehende Aussagen und Qualifikationen übernommen, redaktionell gekürzt

Das Hero-Motiv wurde für diesen Entwurf mit OpenAIs integrierter Bildgenerierung erstellt und ist als Konzeptbild gekennzeichnet.

Vor einer Veröffentlichung sollten alle Leistungsversprechen, Qualifikationsangaben, Kennzahlen und Kundenstimmen rechtlich sowie inhaltlich geprüft werden. Impressum, Datenschutz und ein echtes Porträt von Jonathan fehlen bewusst noch.
